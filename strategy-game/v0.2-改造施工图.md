## 二、目标架构（不推翻闭包，用"依赖注入 + 事件总线"）

### 2.1 新增目录

```
src/
├── core/
│   ├── events.js        # 极简 EventBus：on/off/emit（无 DOM 依赖）
│   ├── status.js        # 中央状态效果：addStatus/tick/has（带 duration、堆叠规则）
│   └── structures.js    # 战场临时对象：工事/炮台/火力区（区别于 sites 据点）
├── factions/
│   ├── factionContext.js # 注入给各联盟模块的能力集（只读 game + 安全动作）
│   ├── factionRegistry.js# 注册/获取联盟系统，统一生命周期
│   ├── hre/{fortification.js,hreRules.js}
│   ├── horde/{raid.js,nomadCamp.js,hordeRules.js}
│   ├── venice/{trade.js,mercenary.js,veniceRules.js}
│   ├── mamluk/{veterancy.js,morale.js,mamlukRules.js}
│   └── ming/{engineering.js,fireZone.js,mingRules.js}
└── main.js              # 只在 7 个埋点 emit，具体逻辑在 factions/
```

### 2.2 关键设计决策

1. **不把闭包内部函数 export 得到处都是**。新建 `factionContext`，在 main.js 内构造一次，暴露联盟系统合法需要的能力：`log/addGold/spendGold/addStatus/hasStatus/addStructure/nearestUnits/...`。联盟模块只依赖 context，不直接碰 DOM、不直接改 UI。
2. **game 新增三个运行时字段**（旧存档缺失时自动补默认值）：
   - `game.factionState`：各联盟系统运行时状态（khanPrestige、mamlukMorale、tradeRoutes[]、loans[] 等）
   - `game.statuses`：单位/格子级时效状态（raided/fortified/crossfire/ambush/stealth…），统一 `{targetId,key,turns,data}`
   - `game.structures`：战场设施（palisade/trench/stonefort/turret/watchtower/supply/fireZone/bridge），`{id,type,owner,x,y,hp,duration,data}`
3. **DOM 与纯逻辑分离**：factions/ 内只算结果并写 game/写 log；UI 层每帧根据 game 渲染。保证 sim 无头可跑。
4. **统一接口**（规格书32节，按本项目裁剪）：每个联盟系统导出 `{id,onTurnStart,onTurnEnd,onBeforeAttack,onAfterAttack,onUnitKilled,onSiteCaptured,onIncome}`，缺省为空函数，由 registry 在对应埋点统一分发。

## 三、分阶段计划与对话分工

> 原则：地基与集成在**主对话**做；五个 Layer 4 系统各自开**附属对话**（省 token，符合 vibe-coding 铁律3）。附属对话只产出 factions/xxx 模块 + 自测，不碰 main.js 主流程和其他联盟。

### 阶段 0：审计与施工图（主对话，本次）
- 产出本文件 + 44 机制处置清单（见第四节）。**不改逻辑。**

### 阶段 1：机制基础设施（主对话，必须先完成且一次做对）
1. events.js：EventBus；在 main.js 七个埋点 emit（先只发事件、无订阅者，验证零行为变化）。
2. status.js：中央时效状态 + beginTurn 时 tick 过期。

## 六、风险与红线

- **存档兼容**：factionState/statuses/structures 三字段读取时缺省补空，旧存档不崩。
- **sim 无 DOM**：任何系统在 headless 下必须可运行，UI 只渲染不决策。
- **AI 后练**：阶段6 之前 AI 不会主动用新系统属预期，不为迁就 AI 简化机制。
- **不破坏现玩法**：每阶段构建+suite 回归，数值变化只允许发生在阶段5。
- **命令环境**：PowerShell 5.1 用 `;` 不用 `&&`；改含中文文件用 Node/Read/Edit，禁用 PowerShell 文本管道；推送由用户执行，AI 只给命令。
- **克制范围**：规格书§46 的复杂系统（人口/粮食/科技树/外交/将领技能树等）本版本一律不做。
