## 4. 当前 UI 限制

- 无最终 UI（阶段 7 才做）。建造/查看通过浏览器控制台 `__hreDebug` 入口：
  - `__hreDebug.eligible('player')` 查看可建造单位与选项
  - `__hreDebug.requestForOwner('player')` 发起建造决策
  - `__hreDebug.pending()` / `__hreDebug.resolve(id, choiceId)` 查看/解析决策
  - `__hreDebug.facilities()` 查看工事状态
- 决策系统无 UI 时自动选第一项（`[decision:auto-resolve]` 标记），**"不建"固定为第一项**，保证 sim 零行为变化；正式 UI 阶段接入 `requestDecision/resolveDecision`，决策点保留。
