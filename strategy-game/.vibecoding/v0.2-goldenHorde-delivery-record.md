## 3. 新增数据结构

## 4. 新增事件 Hook

| 钩子 | 行为 |
|---|---|
| `onTurnStart` | 无条件重置掠袭移动去重标记（raided 作用于被打方，所有 owner 回合都清）→ 营地过期（expireFacilities）→ 维护扣款（initial 回合跳过）→ 仅人类玩家发起建造/营地行动决策 |
| `onBeforeMove` | raided 单位移动预扣 1（付不起则 `cancel`，每回合每单位一次） |
| `onAfterAttack` | 金帐单位攻击：未击杀 → 打 raided 标记（不给金币）；击杀 → 结算战利品（基础+机动/等级+据点，raided 翻倍） |
| 广播 | 营地生产完成后 `ctx.events.emit('productionCompleted', {owner, unit, site:营地facility, kind:'unit'})`（GH-01 契约） |

**未请求新埋点**：GH-01/02/03 已由主对话 v1.2 落地；GH-04/05 降级；GH-06~09 排期。

## 5. 新增玩法

1. **掠袭**（移动经济）：金帐单位击杀敌方单位/据点守军/商队赚金币，"打你就能赚钱"。
2. **raided 疲软**：第一刀制造破绽——被打未死的敌方单位移动-1，且再被金帐击杀时战利品翻倍。
3. **游牧营地**：金帐单位可建营地（不占城市名额、存在 5 回合、2 金币/回合维护、每方上限 2）；营地可生产 5 种金帐单位（轻骑兵/汗国骑兵/骑射手/游牧弓手/游牧战车）；可迁移（原址失去生产功能）；过期自动消失。

## 8. 数值变化（金帐机制最终值，未接线不生效）

### 掠袭战利品（击杀时）

| 目标 | 基础金币 |
|---|---|
| 普通单位 | 3 |
| 高等级单位（level≥3） | 5 |
| 商队/运输单位（transport 或 tradeCaravan/ragusaCaravan） | 6 |
| 站在敌方据点格（袭击据点） | +4 |
| 目标带 raided | ×2 |

**raidPower 加成**（直接加到金币）：move≥5 → +1（轻骑兵/汗国骑兵/骆驼骑兵/快速桨帆船）；level≥3 → +1（汗国骑兵/骆驼骑兵/可汗亲卫/游牧重炮）。例：轻骑兵杀民兵 = 4；汗国骑兵杀高等级 = 7；骆驼骑兵杀商队 = 8。

**未击杀**：0 金币，仅打 raided 标记（turns=3）。

### raided（turns=3 与"持续 1 回合"的关系）

因 tickStatuses 在 **beginTurn 开头对全量存活单位衰减一次**（v1.2 GH-03），raided 写 turns=3：

| 时序 | turns | 效果 |
|---|---|---|
| 金帐攻击后 | 3 | 标记生效 |
| 敌方回合 tick → 2 | 2 | **敌方恰好 1 个完整回合**移动-1 |
| 金帐下轮 tick → 1 | 1 | 金帐再次攻击时战利品翻倍仍生效 |
| 再一轮 tick → 0 | — | 标记移除 |

即"持续 1 回合" = 敌方 1 个完整回合的行动受限 + 金帐下一次行动窗口的收益放大。

### 游牧营地

| 项 | 值 |
|---|---|
| 建造成本 | 25 金币（消耗建造单位本回合行动） |
| 存在 | 5 回合 |
| 维护 | 2 金币/回合（付不起 → 营地解散） |
| 上限 | 每方 2 个 |
| 生产 | 5 种金帐单位，原价，立即部署于营地格 |
| 迁移 | 免费，候选格 = 营地切比雪夫距离 ≤2 的空地（最多列 8 个选项） |
