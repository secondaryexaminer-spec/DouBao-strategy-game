## 3. 你的任务：金帐掠袭与游牧营地系统

### 3.1 核心目标

让金帐玩家的核心决策变成：**"这次攻击是为了击杀，还是为了掠袭后撤？营地放在哪里？要不要迁移？"**

规格书 §2.2/§5.4 的核心循环（移动经济）：

```
战争 → 战利品 → 移动 → 新营地 → 战争
```

金帐的反馈必须是：**"打你就能赚钱。"** 而不是堆属性。

### 3.2 掠袭系统（规格书 §5.1）

金帐单位攻击得利机制。**建议挂在 `afterAttack` 事件**（此时扣血+击杀已处理完，payload 含 `defenderDead`）：

- 每个金帐单位有 `raidPower`（表示掠夺强度，可从 typeMeta 派生或按等级计算，最终数值你定并在报告列出）。
- 触发场景：金帐单位攻击敌方单位 / 敌方据点 / 补给 / 运输单位 / 贸易单位。
- 战利品（金币为主，规格书推荐起点，可调整但必须在报告列最终值）：
  - 普通单位击杀：+3 金币
  - 高等级单位（level≥3）击杀：+5 金币
  - 商队/运输单位（typeMeta.transport）击杀：+6 金币
  - 袭击据点（攻击站据点的单位 / 据点本身）：+4 金币
  - 攻击但未击杀：不给金币或给少量（你定，配合 raided 标记做"第一刀制造破绽"）
- **不直接奖励大量属性**（不给永久攻防）。战利品=金币 + 可选的临时移动力/临时攻击加成（一次行动内，用 status 或直接回合内标记，禁止永久叠加）。

### 3.3 疲软标记 raided（规格书 §5.2）

被金帐单位攻击**但没有死亡**的单位获得 `raided` 状态（status.js，turns=1）：

- 效果：移动力 -1；无法获得完整回血（本回合回血类效果减半或失效，你定）；**继续被金帐攻击时额外获得掠袭收益**（比如 raided 单位被击杀时战利品翻倍，或未击杀也掉金币）。
- 玩法预期：金帐的第一刀不是为了杀，是为了制造破绽。
- 挂点建议：`afterAttack`（defenderDead=false 时给 defender 加 raided）+ `beforeAttack`（attacker 是金帐且 defender 有 raided 时提高战利品/伤害判定）。

### 3.4 游牧营地（规格书 §5.3）

现有"游牧营地"（camp）概念升级为联盟核心系统。**注意：现有营地机制在 main.js 里已存在（CAMP_DURATION/CAMP_COST/MAX_CAMPS_PER_SIDE），你不得修改 main.js 的现有实现**。金帐专属营地系统建议用 facility.js 新建 facility 类型（如 `'nomadCamp'`），在现有营地体系之外运作或作为金帐专属增强，具体方案你设计，但必须遵守：

- 不占永久城市名额；
- 存在 5 回合（duration）；
- **可以迁移**（迁移决策用 decision.js 的 requestDecision/resolveDecision 保留玩家决策点，禁止 autoMigrate）；
- 可生产特定金帐单位（接入 productionCompleted / 或独立生产逻辑，你设计）；
- 每回合消耗少量维护（turnStart 里 spendGold）；
- 迁移后原地点失去生产功能（原 facility 移除或失能）。

### 3.5 兵种联动（金帐专属兵种 × 掠袭/营地）

现有金帐兵种效果保留不动（如"打完就跑"在 main.js 已实现），你只新增联动，不改 constants 数值：

| 兵种 | 建议联动方向（你细化） |
|---|---|
| 轻骑兵/汗国骑兵/骑射手 | 掠袭收益与机动挂钩（高机动单位掠袭距离/收益加成） |
| 游牧战车 | 与营地生产/迁移联动（营地可生产） |
| 可汗亲卫/骆驼骑兵/游牧重炮 | 国家特色兵种，**本对话不做国家机制**，但掠袭系统应对其生效 |

### 3.6 有效 ID（sim 测试用）

- 联盟：`goldenHorde`
- 国家：`goldenHordeCore`（金帐本部）/ `whiteHorde`（白帐）/ `blueHorde`（蓝帐）
- 测试命令见 §1。三国国家机制（可汗威望/绿洲网络/伏击阵地）属于**阶段3**，本对话不实现，但设计时预留挂点（如营地 duration 可被国家加成、掠袭收益可乘区、生产时间可被减少），在交付报告"已知问题"里说明预留了什么。

### 3.7 现有机制处置（施工图 §4）

- **打完就跑**（攻击后保留移动力）：保留·升级——它是掠袭系统的行为底座，本对话不删不改，掠袭逻辑建立其上。
- **金帐本部骑兵攻+1**：重构为可汗威望（阶段3做），本对话不实现。
- **金帐本部营地+2回合**：整合进游牧营地系统（阶段3做），本对话只做联盟级营地本体。
