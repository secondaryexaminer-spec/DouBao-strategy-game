### 核心系统：贸易网络（Layer 4）

依据规格书 §7、§38 实现，但**以本文件为准**（规格书与既有架构冲突时以本文件 + 契约为准）：

**贸易节点**：城市 / 港口 / 特殊商业据点 / 商队单位（己方）。
**建立贸易路线**（`tradeRoute`）：两个己方节点之间建立，需满足：
- 两端可达；
- 中间无敌方控制区域；
- 海路需要己方海军保护。

**收益**：每条贸易路线每回合 +2 金币；路径每额外 2 格 +1 金币；单条上限 +5 金币（避免无限堆路线）。
**可被破坏**：敌军进入路线 → 该路线暂停收入 + 威尼斯收到提示；商队可重新建立路线。

**贸易路线是战场实体（facility），不是 unit status**——按用户第 12 条硬约束与契约 §4 分类，走 `facilitySystem` 统一框架（`createFacility`/`removeFacility`/`damageFacility`/`expireFacility`/`getFacilityAt`/`getFacilitiesByOwner` 已由主对话在 factionContext 补全）。§38 建议的 `{id, owner, startNode, endNode, path, income, status}` 可以作为 facility 的 `data` 承载。

### 玩家决策点（用户硬约束，必须保留）

以下机制必须是"玩家可选择 → 系统执行"，核心 API 用 `ctx.requestDecision(...)` / `ctx.resolveDecision(...)`（契约 §5 decisionSystem），**禁止**设计成 `autoChoose(...)`：
- 哪两座节点建立贸易路线？
- 是否值得承担被切断的风险（建在哪）？
- 热那亚借贷：现在贷 +15 还是等？（借不借、借多少）
- 雇佣兵购买：现在买什么"临时解决方案"？（反骑买长枪兵 / 攻城买投石车 / 远程买弩手）
- 拉古萨中立商港：是否把某敌方港口变为交易港？

无头 sim 自动选选项第一项（如"不建/不贷/维持"），保证不传联盟参数的默认局零行为变化（参考 HRE"不建"、金帐"不建/维持"的 fallback 设计）。

### 三个国家机制（挂点/差异，主对话已批准的 1~3 个/国）

- **威尼斯（veniceCore）**：海上垄断——控制 ≥2 港口时海上贸易路线收益提高、港口生产速度增加；≥3 港解锁"海上霸权"。
- **热那亚（genoa）**：银行信用——花未来收入换当前现金（如立即 +15，随后 3 回合每回合 -6），形成借贷/投资决策；不能无限使用（需冷却或上限）。
- **拉古萨（ragusa）**：中立商港——把部分敌方港口变为"交易港"（条件：不被敌军完全控制 + 拉古萨商队进入）；交易港不完全占领、提供少量收入、为拉古萨贸易网络提供连接。

### 雇佣兵升级（现有机制改造）

现有"非己方联盟兵种 ×1.5"概念升级为"按当前战场购买临时解决方案"（适应能力）。**注意**：这是对 main.js 现有雇佣兵机制（`hire`/`mercenary` 相关）的改动。**如果实现它需要修改 main.js / combat.js / movement.js / factionContext.js / factionRegistry.js 或契约，先停下报告主对话，不得自行修改**；先做贸易网络与三国机制，雇佣兵升级可作为可选扩展或挂点预留，在交付报告中说明现状。
